# AI Working Journal

## Overview

I used AI as a coding assistant during this project.

I mainly used it when I was stuck, needed help finding an issue, wanted to check my code, or wanted a second opinion on an implementation.

I wrote and tested the code myself and made the final decisions on what to use.

## Project Setup

I used AI to review my project structure and check if the frontend and backend were organised in a simple way.

I also used it to help with small setup issues when they came up during development.

## Backend

I used AI mainly for:

- Reviewing FastAPI routes
- Checking API request and response handling
- Troubleshooting backend errors
- Reviewing database queries
- Checking CRUD operations

When I got an error, I shared the related code and error message with AI to help find the possible cause.

I then tested the suggested fix before using it.

## PostgreSQL

I used AI to help with:

- PostgreSQL connection issues
- SQLAlchemy setup
- Database models
- Query errors
- CRUD operations

I checked the changes locally to make sure they worked with my application.

## Frontend

I used AI to help with:

- React component issues
- API connection problems
- Form handling
- Loading and error states
- Small UI improvements

I kept the frontend simple and due to time constraint and spent most of the time on the backend processing.

## Debugging

AI was mainly useful when I was debugging.

My usual process was:

1. Find the issue myself.
2. Check the error and related code.
3. Ask AI to help identify the possible cause.
4. Review the suggested solution.
5. Apply the change.
6. Test the application again.

This helped me understand and fix issues instead of blindly applying changes.

## Code Review

I used AI to review parts of the code after implementing them.

I mainly checked for:

- Unnecessary code
- Repeated code
- Naming issues
- Simple error handling improvements
- Code readability

I kept the changes that made sense for the project and removed suggestions that added unnecessary complexity.

## Testing

I also used AI to suggest some additional cases to test.

I tested things such as:

- Normal input
- Empty fields
- Invalid input
- API errors
- Database errors
- Frontend error states

I tested the application myself after making changes.

## Git

I used AI occasionally when I needed help with Git commands or Git issues.

This included things such as:

- Resolving simple Git issues

## How I Used AI Overall

I used AI as a support tool during development, mainly for debugging, code review, and solving specific coding problems.

My general workflow was:

**Understand → Build → Test → Debug → Review → Improve**

I did not use AI to build the entire project for me. I made the main implementation decisions, wrote and tested the code, and reviewed the AI suggestions before using them.
